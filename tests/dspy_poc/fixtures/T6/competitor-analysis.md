   - **Traction:** Used by 20,000+ healthcare providers [estimate - training data, unverified]

   - **JTBD Match:** Adjacent (secure video but lacks session structure)

3. **Gather app**
   - **What they offer:** Intimate group video sessions with breakout rooms
   - **Traction:** Popular for small group meetings [estimate - training data, unverified]

**Switching Analysis:**

- **Lock-in factors:** Data integration, familiar interfaces, existing schedules
- **Switch triggers:** Better session structure tools, specialized therapeutic features
- **Switching Cost:** Low (users can quickly adopt new platforms for specialized needs)

**Competitive Gaps & Challenges:**

**Gaps:**
- No platform combines **secure video + structured wish-exchange framework** [validated - user sentiment]
- Missing **psychologist-controlled session orchestration** tools [validated - user complaints]
- Lack of **closed patient-community integration** [validated - user requests]

**Challenges:**
1. **Market education:** Need to teach psychologists about wish-exchange benefits
2. **Switch inertia:** Users comfortable with existing video tools resist change
3. **Feature complexity:** Balancing structure with ease-of-use for non-tech users
