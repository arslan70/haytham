# Example: AI-Powered Git Changelog CLI

**Idea:** A CLI tool that uses LLMs to generate meaningful changelogs from messy git commit history.

**Verdict:** GO (MEDIUM risk) | Composite Score: 3.6/5.0

Clear pain point with a narrow differentiator. Existing tools (conventional-changelog, git-cliff, semantic-release) are rule-based and require disciplined commit conventions. Most teams don't have disciplined commit conventions. An AI-powered tool handles the real world: squash merges, vague messages, mixed concerns in single commits.

Main risks: LLM cost per invocation, accuracy of commit classification, and competing with entrenched free/OSS tools.
